# 设计原则

## 设计哲学

**Warm Cream** — 奶油温暖底色 + 电光蓝强调 + 大留白 + 有机圆角。温暖亲和但不甜腻，蓝色提供现代科技感。视觉调性对标小红书质感 × Bear 编辑器的温暖 × Notion 的克制。

关键词：`温暖` · `亲和` · `大留白` · `有机` · `精致`

## 间距与圆角

| 属性 | 值 |
|------|-----|
| 间距阶梯 | 4 xs / 8 sm / 16 md / 20 lg / 28 xl / 40 xxl / 56 xxxl |
| 圆角阶梯 | 10 sm / 14 md / 20 lg / 24 xl / 28 xxl / pill(999) |
| 触控目标 | 最小 44pt |

> **有机圆角原则：** 圆角比纯 iOS HIG 更大（20-28px），营造温暖亲和的"软"触感。

## 阴影系统 — 暖色调阴影

| 场景 | iOS |
|------|-----|
| 卡片 | `shadow(rgba(120, 100, 70, 0.45), 0 4px 16px, opacity: 0.12)` |
| 浮动元素 | `shadow(rgba(120, 100, 70, 0.50), 0 8px 24px, opacity: 0.15)` |

> **暖阴影原则：** 阴影使用金棕色调（`rgba(120, 100, 70, ...)`），而非冷灰色，让卡片"浮"在暖底色上时看起来自然融洽。

## 组件模式

### 底部导航（浮动圆角胶囊）
- 4 Tab：探索 / 规划 / 记录 / 我的
- 浮动离底部 24px，左右 20px，圆角 24px
- 背景：BlurView 毛玻璃（iOS）/ 暖半透明白（Web）
- 暖色调阴影
- 激活态：蓝色 `accentSoft` 背景包裹图标，蓝色 tint
- 未激活态：`textTertiary` 灰色图标

### 页面信息头（替代生硬大标题）
- 顶部不直接放 `largeTitle` 单行大字
- 使用暖白信息卡：上方小号 eyebrow + 中号标题 + 一行解释文案
- 右上角只放状态胶囊或主动作，不再让标题本身承担全部视觉重量
- Explore 页的信息头允许半透明浮在地图上；Plan / Tracker / Profile 页贴合内容流
- 页面文案统一使用中文，避免中英混排造成视觉断裂

### 分段控制（模式切换）
- `bgWash` 暖灰底色，`bgCard` 白色 + cardShadow 活跃段
- 用于 Plan 页和 Profile 页

### 卡片
- 白色背景（`bgCard`）+ 暖色调阴影 + 大圆角（20-24px）
- 无边框，靠阴影区分层级
- 列表项内部使用 hairline 分隔线

### 路线卡片
- 300x184px，圆角 24px
- 暖阴影，选中态电光蓝边框
- 底部文字信息 + 暖白色半透明主题 pill

### 收藏按钮
- 使用 `heart` 暖红色（`#FF6B6B`），不使用冷红
- 44pt 触控区域

### 标签气泡
- 未选中：`bgWash` 暖灰底（无边框）
- 选中：`accent` 蓝色实底 + 白色文字

### Poster 卡
- 深色背景（warm charcoal 渐变 `#1C1917` → `#292524` → `#44403C`）
- 保持唯一的"反色"场景
- 内部使用 `rgba(255,255,255,0.06)` 的微妙层级

### 空状态
- 64px 圆角方块 + `bgWash` 底色 + 灰色线框图标
- 温暖但不过分装饰

## 设计反模式（禁止事项）

1. **禁止冷灰色** — 所有灰色必须带暖色调（stone 系），不使用 slate/zinc 系冷灰
2. **禁止纯黑文字** — 主文字使用 `#1C1917` warm charcoal，非 `#000000`
3. **禁止冷色阴影** — 阴影使用金棕色调，非 `rgba(0,0,0,...)`
4. **禁止过度渐变** — 渐变仅用于 Poster 卡背景，其他场景用实色
5. **禁止生硬边框** — 卡片靠阴影区分，内部列表可用 hairline 但不加 border
